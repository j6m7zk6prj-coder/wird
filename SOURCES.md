# Wird — sources

## Texte du Coran
Texte uthmani de **Tanzil** (https://tanzil.net), version 1.1, intégré **tel quel** (fichier `Wird/quran.json`).

> Tanzil Quran Text — Copyright (C) 2007-2021 Tanzil Project — License: Creative Commons Attribution 3.0.
> Permission is granted to copy and distribute verbatim copies of this text, but changing it is not allowed.

Copie utilisée : instantané publié par le projet *quran-json* (Risan Bagja), qui conserve l'empreinte SHA-256 du fichier téléchargé chez Tanzil.

Vérifications faites avant de l'intégrer :
- 114 sourates, 6 236 versets, le bon nombre de versets dans chaque sourate ;
- lettre par lettre, chaque verset a été comparé au texte du **Complexe du Roi Fahd** (édition KFGQPC Hafs, via Quranpedia) : 0 différence ;
- la basmala que Tanzil place au début du premier verset des sourates 2 à 114 (sauf la 9) est affichée en tête de sourate, comme dans le Mushaf. Le texte n'est pas modifié.

## Tajwid
Annotations du projet **quran-tajweed** de Collin Fair (https://github.com/cpfair/quran-tajweed), licence Creative Commons Attribution 4.0, recalculées avec son propre classificateur sur ce texte de Tanzil.

## Police
**Amiri Quran**, par Khaled Hosny — SIL Open Font License 1.1 (voir `Wird-OFL-Amiri.txt`).

## Pages et juz
Numéros de page (Mushaf de Médine, 604 pages) et de juz de chaque verset, d'après les données du **Complexe du Roi Fahd** (KFGQPC Hafs Smart, version 8), fichier `mushaf.json`. Seuls les numéros sont repris, pas le texte.

## Récitations
Les récitations sont lues en ligne depuis everyayah.com (rien n'est intégré à l'app).
